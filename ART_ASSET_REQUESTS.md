# Iron Horizon Art Asset Requests

Imagen 2-specific tooling is not available in this Codex session. The prototype uses procedural placeholder art so the game remains playable. Use the prompts below for a future art pass.

## Style Guide

- Perspective: strict top-down gameplay readability for ships, aircraft, torpedoes, wakes, and FX
- Era: original WW2-inspired naval warfare, not direct copies of any existing game UI or branded assets
- Tone: steel, smoke, sea spray, readable silhouettes, restrained nation color accents
- Rendering: painterly-realistic with clean silhouettes and high contrast at small sizes
- Output: transparent PNG sprite sheets where applicable, plus layered source if possible

## Menu Background
